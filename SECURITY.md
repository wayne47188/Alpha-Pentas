# Security Policy

Alpha Pentas is in **pre-release development**. It is not certified or production-ready.

## Reporting vulnerabilities
Do **not** disclose exploitable details in public Issues or PR comments. Use GitHub's private vulnerability reporting under Repository Settings → Security → Code security and analysis, if enabled. If that channel is not available, ask maintainers for a private reporting channel before sharing sensitive details.

Provide affected version/commit, impact, reproduction in a safe isolated environment and suggested mitigation. Never include third-party credentials, customer IPs or live target evidence.

## Scope / authorization
This project is intended only for legal, written-authorized security testing. Unauthorized deployment, access or collection is outside project policy.

## Maintenance
Supported versions and coordinated disclosure windows will be declared before the first release. Until then, security fixes are best-effort and deployment is not recommended.
