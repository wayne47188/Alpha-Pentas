# Contributor Code of Conduct

We are committed to a professional, inclusive and technically constructive open-source environment.

## Expected
- Discuss code and architecture with evidence, precision and respect.
- Welcome useful criticism and ask clarifying questions.
- Respect confidentiality, lawful authorization, secure disclosure and user privacy.
- Review contributions on technical merit.

## Unacceptable
Harassment, threats, discriminatory conduct, disclosure of private information, knowingly unsafe guidance, or exposing real customers' security data.

## Enforcement
Maintainers may moderate, request corrections, close threads or revoke project access. To report conduct issues privately, use an appropriate private contact channel established by the maintainers. Do not publish personal details in public reports.

This policy supplements GitHub's terms and community guidelines.
